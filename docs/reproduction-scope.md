# Reproduction Scope

The original project archive is private and contains competition-controlled data, result packages, model checkpoints, defense materials, and environment-specific files.

This public repository intentionally provides only:

- the English project description;
- the high-level method;
- reported results;
- the public release boundary.

It intentionally excludes all model weights, competition images, official output packages, private validation data, raw logs, internal paths, and third-party base models.

To reproduce the method independently, prepare legally shareable image-enhancement data, compatible diffusion base models, an NVIDIA GPU environment, and a new evaluation protocol. Do not assume that the official score will transfer to a different dataset or implementation.
